# Лабораторная работа №1. Основы 3D-графики

## Вариант и цель работы

**Вариант 10: правильный додекаэдр.**

Цель работы — изучить построение простых 3D-объектов, проекцию на 2D-плоскость,
матрицы перспективной и ортографической проекции, аффинные преобразования, а
также реализовать интерактивное приложение на Vulkan + GLFW + ImGui.

В работе реализованы все дополнительные задания, поэтому работа рассчитана на
оценку **5**.

## Что реализовано

Приложение отображает правильный додекаэдр в реальном времени и позволяет:

- переключать перспективную и ортографическую проекцию;
- менять положение, поворот и масштаб фигуры;
- запускать и ставить на паузу анимацию движения по сложной траектории;
- менять скорость анимации, радиус траектории, амплитуду по вертикали, фазу и
  скорость вращения;
- менять цвет фигуры через `ColorEdit3`;
- использовать процедурные цвета вершин, которые умножаются на выбранный цвет;
- отображать несколько объектов, у каждого из которых собственный
  `VkDescriptorSet` и собственный uniform-буфер.

Дополнительно реализованы:

- управление камерой (yaw, pitch, distance);
- настройка полей зрения и плоскостей отсечения;
- простое диффузное и зеркальное освещение;
- корректировка нормалей при неравномерном растяжении через
  `transpose(inverse(model))`;
- кнопка сброса сцены и кнопка сброса времени анимации.

## Сборка и запуск

```bash
cmake --preset debug
cmake --build build-debug --parallel
./build-debug/vulkan-starter-app
```

Запускать приложение нужно из корня проекта, потому что шейдеры загружаются по
относительному пути `shaders/*.spv`.

Для сборки шейдеров используется `glslc`, а если его нет — `glslangValidator`
(эта возможность добавлена в `CMakeLists.txt`).

## Построение додекаэдра

Правильный додекаэдр имеет 20 вершин, 30 рёбер и 12 пятиугольных граней.
Вершины задаются через золотое сечение `phi = (1 + sqrt(5)) / 2`:

- `(±1, ±1, ±1)`;
- `(0, ±1/phi, ±phi)`;
- `(±1/phi, ±phi, 0)`;
- `(±phi, 0, ±1/phi)`.

После генерации все вершины масштабируются так, чтобы радиус описанной сферы
был равен 1.

Грани находятся автоматически: перебираются все тройки вершин, для каждой
тройки строится плоскость, и проверяется, что ровно пять вершин лежат в этой
плоскости, а все остальные — по одну сторону от неё. Это позволяет получить все
12 пятиугольников без ручного перечисления индексов.

Каждая пятиугольная грань разбивается на три треугольника («веером» от первой
вершины). Вершины дублируются для каждой грани, поэтому нормаль у грани плоская
(flat shading), и пятиугольные грани хорошо различимы при освещении.

Цвет вершины вычисляется процедурно из её локальной позиции:

```cpp
color = {
    0.5 + 0.5 * x / radius,
    0.5 + 0.5 * y / radius,
    0.5 + 0.5 * z / radius,
};
```

В шейдере этот цвет умножается на цвет, выбранный пользователем в ImGui. При
белом цвете в интерфейсе фигура показывает исходные процедурные цвета, при
другом цвете — тонируется им.

## Матрицы и проекции

В `source/math.hpp` реализованы матрицы в формате column-major, который
ожидает GLSL.

Модельная матрица собирается как:

```text
model = T(position) * Rz * Ry * Rx * S(scale)
```

То есть сначала применяется растяжение, затем повороты и только потом перенос.

Матрица вида строится через `lookAt`, камера вращается вокруг начала координат
параметрами yaw, pitch и distance.

Перспективная матрица учитывает, что в Vulkan глубина находится в диапазоне
`[0, 1]`, а не `[-1, 1]`, как в OpenGL:

```text
f = 1 / tan(fov / 2)

[ f/aspect   0          0                         0 ]
[ 0          f          0                         0 ]
[ 0          0          far/(near-far)            -1 ]
[ 0          0          far*near/(near-far)        0 ]
```

Ортографическая матрица также переводит глубину в `[0, 1]`:

```text
[ 2/(right-left)  0                0                 0 ]
[ 0               2/(top-bottom)   0                 0 ]
[ 0               0                1/(near-far)     0 ]
[ -(right+left)/(right-left)  -(top+bottom)/(top-bottom)  near/(near-far)  1 ]
```

Итоговая матрица, передаваемая в шейдер:

```text
mvp = projection * view * model
```

### Переключение проекции

В интерфейсе есть выпадающий список `Projection`:

- `Perspective` — используется `math::perspective`;
- `Orthographic` — используется `math::orthographic`.

Переключение происходит каждый кадр, матрица пересчитывается динамически, без
пересоздания пайплайна.

## Трансформации объекта

Для основной фигуры в интерфейсе доступны:

- `Position` — перенос по X, Y, Z;
- `Rotation` — поворот по X, Y, Z в градусах;
- `Stretch / scale` — независимое растяжение по осям.

При неравномерном масштабе нормали в вершинном шейдере преобразуются через
обратную транспонированную матрицу:

```glsl
mat3 normal_matrix = mat3(transpose(inverse(ubo.model)));
fragNormal = normal_matrix * inNormal;
```

Это сохраняет корректное освещение при растяжении фигуры.

## Анимация по сложной траектории

Анимация задаёт смещение основной фигуры по траектории Лиссажу:

```text
x = radius * sin(t)
y = vertical_amplitude * sin(2t + phase)
z = radius * cos(t)
```

Дополнительно фигура вращается сразу по трём осям с разными коэффициентами:

```text
rotationX = baseX + spin_speed * t * 0.65
rotationY = baseY + spin_speed * t
rotationZ = baseZ + spin_speed * t * 0.25
```

В интерфейсе есть:

- `Play` — пауза и воспроизведение;
- `Reset trajectory` — сброс времени;
- `Speed` — скорость анимации;
- `Trajectory radius` — радиус траектории;
- `Vertical amplitude` — амплитуда по вертикали;
- `Spin speed` — скорость вращения;
- `Trajectory phase` — фаза траектории.

Время анимации накапливается только когда анимация воспроизводится:

```cpp
if (animation.playing) {
    animation.time += ImGui::GetIO().DeltaTime * animation.speed;
}
```

Поэтому пауза замораживает фигуру в текущей точке траектории, а параметры
траектории можно менять и во время движения.

## Цвет и освещение

Цвет фигуры меняется через `ImGui::ColorEdit3`. Процедурный цвет каждой вершины
умножается на выбранный цвет в вершинном шейдере:

```glsl
fragColor = inColor * ubo.baseColor.rgb;
```

Во фрагментном шейдере есть:

- окружающее освещение;
- диффузное освещение по направлению света;
- слабая подсветка обратной стороны;
- зеркальный блик.

Это делает форму читаемой при любой проекции и повороте.

## Несколько объектов и несколько VkDescriptorSet

В сцене три объекта. Для каждого создаётся:

- собственный uniform-буфер (`VkBuffer`);
- собственный `VkDescriptorSet`;
- запись дескриптора через `vkUpdateDescriptorSets`.

Все три набора аллоцируются из одного `VkDescriptorPool`, но каждый содержит
указатель на свой uniform-буфер. При отрисовке для каждого объекта выполняется:

```cpp
vkCmdBindDescriptorSets(..., &gpu_objects[i].descriptor_set, ...);
vkCmdDraw(..., vertex_count, 1, 0, 0);
```

Таким образом, один и тот же меш додекаэдра рисуется несколько раз с разными
модельными матрицами, цветами и трансформациями. Это и есть демонстрация
работы с несколькими `VkDescriptorSet`: объекты отличаются не содержимым
вершинного буфера, а данными, переданными через разные наборы дескрипторов.

Два дополнительных объекта можно включать и выключать, менять их цвет,
позицию и масштаб в разделе `Additional objects`.

## Управление

- Мышь и клавиатура для ImGui — стандартные.
- Все параметры сцены меняются через окно `Laboratory 1 - Dodecahedron`.
- Камера управляется ползунками `Yaw`, `Pitch`, `Distance`.
- `Reset scene` возвращает начальные трансформации, цвета, камеру и проекцию.
